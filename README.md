# Трекер тренировок

Файлы:
- `program.md` — программа (верх/низ, 4 дня), правила прогрессии, мезоцикл.
- `log.md` — дневник. Одна тренировка = один блок. Новые блоки добавляй **сверху** (копируй шаблон из `template.md`).
- `body.md` — вес, талия, обхваты, давление (раз в неделю / 2 недели).

## Как заполнять в зале
Формат подхода: `вес×повторы` (RIR в скобках, если отличается от плана).
Пример: `80×8, 80×7, 77.5×8 (RIR0)`.

## Правило прогрессии
Все рабочие подходы упражнения достигли верхней границы повторов при целевом RIR →
в следующий раз +2.5–5% веса (изоляция +1–2 кг) и снова от нижней границы.
Базу (жимы) — не более ~5% в неделю. Жим лёжа без отбива, 1–3 RIR, не до отказа.

## Сигналы для внеплановой разгрузки
2 тренировки подряд падают повторения при том же RIR · плохой сон · пульс покоя растёт · боль в сухожилии >3–5 дней.
