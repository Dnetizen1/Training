# Дневник тренировок

Трекер под программу «верх/низ, 4 дня» из исследования: журнал подходов, отдых со звуковым сигналом,
нагрузка на мышцы по шкале 0–10, объём за неделю, перенос пропущенного, тренер-помощник.

Дизайн в духе Apple Health / Fitness: вкладки «Сводка · Тренировка · Неделя · История · Тренер»,
кольца недели, личные рекорды, история упражнения с графиком, калькулятор блинов. Светлая или тёмная тема —
по настройке телефона. Макет дизайна: https://claude.ai/artifact/E7r61u6nLNSxHS8iDcLWBq

Два вида экрана тренировки на одних данных (переключаются в меню дня: нажми на название тренировки):
- **Журнал** — таблица подходов, как в Strong/Hevy.
- **По одному подходу** — одно упражнение и один подход на экране, крупные кнопки ±, кольцо отдыха. Сверстан точно по макету.

## Как запускать

### 1. Как артефакт Claude (основной способ)
Всё работает, включая сохранение в облаке и тренера:
https://claude.ai/artifact/WBxuoNExCmZ6CVGjUb3mNN

На iPhone удобнее открывать в приложении Claude: в Safari нижнюю панель может перекрывать панель браузера.

### 2. Локально, просто открыть файл
Скачай `tracker.html` и открой в браузере (двойной клик). Записи сохраняются в памяти этого браузера.
Без Claude не работают: облачное сохранение, тренер, разборы и автоопределение мышц для незнакомых
упражнений (знакомые берутся из встроенного справочника и работают).

### 3. Как сайт через GitHub Pages
В репозитории: Settings → Pages → Source: «Deploy from a branch», ветка `master`, папка `/ (root)`.
Через минуту страница будет по адресу `https://<логин>.github.io/Training/tracker.html`.
Работает так же, как в пункте 2: данные в браузере, без тренера.

## Как менять

`tracker.html` собирается из `src/`, руками его не правь:

```
python3 build.py        # собрать tracker.html из src/
```

| Файл | Что внутри |
|---|---|
| `src/data.js` | программа, аналоги упражнений, список мышц, нагрузка по упражнениям программы |
| `src/exdb.js` | открытая база упражнений [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain), сгенерирована `tools/import_exdb.py` |
| `src/core.js` | модель, хранилище, справочник мышц (по ExRx), перенос пропущенного, промпты, звук |
| `src/ui.js` | вид «Журнал», недели, история, замеры, чат тренера, приложение |
| `src/home.js` | «Сводка»: кольца недели, рекорды, прогресс, история упражнения |
| `src/focus.js` | вид «Фокус» |
| `src/ios.css` | стили (в духе iOS, светлая/тёмная тема по системе) |
| `DESIGN.md` | почему интерфейс устроен так (Strong/Hevy, фокус-режим, анти-клише) |
| `tools/import_exdb.py` | обновить `src/exdb.js` из свежей версии базы |

Чтобы обновить артефакт Claude после правок: собрать `tracker.html` и попросить Claude опубликовать его по той же ссылке.

Ветка `v1-journal` — дизайн до появления вида «Фокус». Дизайн до перехода на стиль iOS — в истории git (коммит перед «Apple Health / Fitness redesign»).

## Текстовые файлы (запасной вариант)
- `program.md` — программа и мезоцикл.
- `log.md`, `template.md` — дневник в markdown.
- `body.md` — замеры.

## Источники
- Состав мышц в упражнениях — [ExRx](https://exrx.net) (target / synergists; стабилизаторы не считаются).
- Шкала нагрузки 0–10 — как в приложении «Твой тренер».
- Раскладка — по образцу Strong и Hevy, фокус-режим — по рекомендациям для фитнес-приложений (одно действие на экран, крупные цели касания).
