# Дизайн дневника тренировок

## Референс: Strong и Hevy
Это два самых популярных журнала для зала. У обоих один и тот же «скелет», и он такой не случайно:

| Решение | Почему так |
|---|---|
| Один экран «журнала»: упражнения идут списком, без карточек и модалок | В зале телефон держат одной рукой между подходами. Любой лишний экран стоит времени отдыха. |
| Таблица подходов: № · ПРЕДЫДУЩИЙ · КГ · ПОВТ · ✓ | Прогрессия = «сделать больше, чем в прошлый раз». Прошлый результат стоит в той же строке, его не надо искать. |
| Выполненный подход подсвечивается всей строкой | Состояние читается боковым зрением, без вчитывания. |
| Галочка запускает таймер отдыха | Это то, что человек и так сделал бы следующим. |
| Пустые поля показывают прошлые значения серым, галочка их подставляет | Повторить прошлый результат одним нажатием. |
| Действия с упражнением спрятаны в «⋯» | В строке остаётся только то, что нужно в каждом подходе. Замена или удаление нужны редко. |
| Нижняя панель вкладок | Зона большого пальца. Верх экрана на телефоне недосягаем одной рукой. |
| Название упражнения цветом акцента | Это главный ориентир при прокрутке. |
| Столбец усилия по подходу (Hevy: RPE) | Необязательный. Пусто — значит не заполнял. |
| Сводка после «Завершить»: время, подходы, объём | Закрывает тренировку и даёт повод разобрать её. |

## Что берём и что меняем
- Берём: скелет экрана, таблицу подходов, «⋯»-меню, нижние вкладки, сводку в конце, таймер тренировки в шапке.
- Своё: вместо RPE — **запас повторов** (RIR), потому что программа написана в RIR. Цвета дисков IWF как цвета дней. Разбивка по мышцам с делением спины.
- Не берём: анимированные инструкции, соцленту, графики (пока).

## Токены
- Цвета: фон `--bg`, поверхность `--surface`, линии `--line`, акцент дня `--day` (синий / красный / жёлтый / зелёный диск), выполнено `--ok`.
- Шрифты: Unbounded — только название экрана и крупные цифры; Golos Text — весь текст; JetBrains Mono — веса, повторы, таблицы.
- Радиусы: 4px поля и кнопки, 10px шторки снизу. Карточек нет — разделители.
- Движение: Motion, пружины только на шторках, всплывашках и галочке.

## Анти-клише
Без Inter, без пилюль, без капс-подписей над заголовками, без одинакового радиуса у всего, без длинных тире в интерфейсе, без слова «ИИ»/«Клод» в кнопках — помощник называется «тренер», действия — «автоматически».
