# Предыдущий дизайн (журнал по образцу Strong/Hevy)

## Референс: Strong и Hevy
Это два самых популярных журнала для зала. У обоих один и тот же «скелет», и он такой не случайно:

| Решение | Почему так |
|---|---|
| Один экран «журнала»: упражнения идут списком, без карточек и модалок | В зале телефон держат одной рукой между подходами. Любой лишний экран стоит времени отдыха. |
| Таблица подходов: № · ПРЕДЫДУЩИЙ · КГ · ПОВТ · ✓ | Прогрессия = «сделать больше, чем в прошлый раз». Прошлый результат стоит в той же строке, его не надо искать. |
| Выполненный подход подсвечивается всей строкой | Состояние читается боковым зрением, без вчитывания. |
| ~~Галочка~~ → кнопка «Подход N сделан · отдых» под таблицей | Дозаполняет текущий подход прошлыми значениями и запускает отдых со звуковым сигналом в конце. Подход считается сделанным, если записаны повторы — так «Журнал» и «Фокус» видят одно и то же. |
| Пустые поля показывают прошлые значения серым, галочка их подставляет | Повторить прошлый результат одним нажатием. |
| Действия с упражнением спрятаны в «⋯» | В строке остаётся только то, что нужно в каждом подходе. Замена или удаление нужны редко. |
| Нижняя панель вкладок | Зона большого пальца. Тренер — пятой кнопкой. Таймер отдыха и всплывашка «Вернуть» — липкой полосой сверху. В браузере iPhone низ окна может перекрывать панель Safari; в приложении Claude этого нет. |
| Название упражнения цветом акцента | Это главный ориентир при прокрутке. |
| Столбец усилия по подходу (Hevy: RPE) | Необязательный. Пусто — значит не заполнял. |
| Сводка после «Завершить»: время, подходы, объём | Закрывает тренировку и даёт повод разобрать её. |

## Что берём и что меняем
- Берём: скелет экрана, таблицу подходов, «⋯»-меню, нижние вкладки, сводку в конце, таймер тренировки в шапке.
- Своё: вместо RPE — **запас повторов** (RIR), потому что программа написана в RIR. Цвета дисков IWF как цвета дней. Разбивка по мышцам с делением спины.
- Состав мышц — по ExRx (target / synergists, стабилизаторы не считаем): встроенный справочник по ключевым словам названия; модель — только для незнакомых упражнений и со строгими правилами.
- Из «Твой тренер»: **нагрузка на мышцу по шкале 0–10** для каждого упражнения (высокая 7–10, средняя 4–6, низкая 1–3) с подсветкой строк. В объём недели: высокая = 1 подход, средняя = 0,5, низкая = 0,25 — так вспомогательные мышцы в тренажёрах не завышают объём.
- Не берём: анимированные инструкции, соцленту, графики (пока), «объём в кг» (тоннаж ничего не говорит о гипертрофии).
- После «Завершить» — перенос недобора в ближайшие тренировки (простое правило с лимитом +4 подхода и 1 новое упражнение на тренировку, или подбор тренером). Применяется, когда открываешь ту тренировку.
- Упражнения чередуются полосами (темнее/светлее), чтобы глаз не терял строку.

## Токены
- Цвета: фон `--bg`, поверхность `--surface`, линии `--line`, акцент `--day` — один тёплый оранжевый (синий не нравится); цвет дня остаётся только на значке-диске; выполнено `--ok`.
- Шрифты: Unbounded — только название экрана и крупные цифры; Golos Text — весь текст; JetBrains Mono — веса, повторы, таблицы.
- Радиусы: 4px поля и кнопки, 10px шторки снизу. Карточек нет — разделители.
- Движение: Motion, пружины только на шторках, всплывашках и галочке.

## Анти-клише
Без Inter, без пилюль, без капс-подписей над заголовками, без одинакового радиуса у всего, без длинных тире в интерфейсе, без слова «ИИ»/«Клод» в кнопках — помощник называется «тренер», действия — «автоматически».

# Вид «Фокус» (второй дизайн, переключается кнопкой)
Противоположный подход: не журнал, а «ведущий» экран. Источники: Stormotion, zfort, UXmatters о фитнес-приложениях — одно действие на экран, крупные цели касания (≥44–48pt, у нас 68–72px), минимум ввода с клавиатуры, читаемость с вытянутой руки.

| Решение | Почему |
|---|---|
| Одно упражнение и один текущий подход | Между подходами смотришь на экран 2 секунды. Ничего лишнего. |
| Вес и повторы — огромные цифры с кнопками ± (вес шаг 2,5, повторы 1), тап по цифре — ввод | Без клавиатуры, потными руками. Значения уже стоят по прошлому подходу или прошлой тренировке. |
| Одна главная кнопка «Подход сделан» | Единственное частое действие — самое большое. |
| Кольцо отдыха с «Дальше: …» | Отдых и следующий шаг видны издалека. |
| Полоса прогресса: сегмент на упражнение | Где я в тренировке, без списка. |
| Тёмная «сцена», одна тема | Сознательный выбор для зала; акцент — цвет диска дня. |

Данные, недели, история, замеры, тренер и перенос пропущенного — общие для обоих видов. Вид «Журнал» сохранён (git-метка `v1-journal`).
